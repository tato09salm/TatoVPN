:: ============================================================
:: SCRIPT DE RECUPERACIÓN DE INTERNET / RESTAURACIÓN DE RED
:: Ejecutar este archivo o los comandos en CMD como ADMINISTRADOR
:: ============================================================

:: 1. Terminar procesos residuales que puedan secuestrar el tráfico
taskkill /F /IM tun2socks.exe /T
taskkill /F /IM xray.exe /T
taskkill /F /IM v2ray.exe /T
taskkill /F /IM ssh.exe /T
taskkill /F /IM TatoVPN.exe /T

:: 2. Desactivar el proxy del sistema (evita error "sin conexión al proxy")
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings" /v ProxyEnable /t REG_DWORD /d 0 /f
netsh winhttp reset proxy

:: 3. Deshabilitar interfaz virtual de VPN si quedó activa
netsh interface set interface name="TatoVPN" admin=disable

:: 4. Eliminar reglas residuales de Firewall
netsh advfirewall firewall delete rule name="TatoVPN_Block_Outbound_UDP"
netsh advfirewall reset

:: 5. Limpieza de rutas residuales
route delete 0.0.0.0 mask 128.0.0.0
route delete 128.0.0.0 mask 128.0.0.0

:: 6. Reset completo del catálogo Winsock y TCP/IP
netsh winsock reset
netsh int ip reset

:: 7. Restaurar DNS a DHCP para Wi-Fi y Ethernet
netsh interface ipv4 set dnsservers name="Wi-Fi" source=dhcp
netsh interface ipv6 set dnsservers name="Wi-Fi" source=dhcp
netsh interface ipv4 set dnsservers name="Ethernet" source=dhcp
netsh interface ipv6 set dnsservers name="Ethernet" source=dhcp

:: 8. Reiniciar la interfaz Wi-Fi
netsh interface set interface name="Wi-Fi" admin=disabled
netsh interface set interface name="Wi-Fi" admin=enabled

:: 9. Refrescar asignación IP y caché DNS
ipconfig /flushdns
ipconfig /release
ipconfig /renew

:: 10. Probar conectividad
ping 8.8.8.8

:: NOTA: Si después de ejecutar todo esto no navega de inmediato,
:: reinicia la PC para aplicar los cambios de Winsock y TCP/IP.
